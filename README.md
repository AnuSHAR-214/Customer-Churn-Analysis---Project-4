# Customer-Churn-Analysis---Project-4
Used Python, SQL, and Tableau  
1. Analysed Telco customer churn data using Python for cleaning/EDA and SQL for business queries. 
2. Built a Tableau dashboard with KPIs and visuals to track churn by contract, tenure, and charges.
3. Identified key churn drivers (month-to-month plans, low tenure, high charges) and recommended retention strategies.
